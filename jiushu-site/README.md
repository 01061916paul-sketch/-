# 九澍團隊網站

九澍有限公司團隊簡介網站。純靜態網頁，不需要安裝或編譯。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體（內容、樣式、互動程式） |
| `scrollcraft.css`、`scrollcraft.js` | 捲動效果引擎 |
| `assets/` | 肖像與作品照片 |

## 用 GitHub Pages 上線

1. 把這個資料夾的所有檔案推到一個 GitHub repository 的根目錄。
2. 到 repository 的 **Settings → Pages**。
3. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一兩分鐘後，網址會出現在同一頁，格式是 `https://<帳號>.github.io/<repository 名稱>/`。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可。字體從 Google Fonts 載入，離線時會改用系統宋體。
